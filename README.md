## Recipe Finder - web app

Recipe finder is a full application that helps you find the recipes you would like, with some catchy designs and modern animations, you can access details or each recipe, search for any dish, add it to your favorites, and bon appetite!

The app to review: https://recipefinder-k.netlify.app/

what does this app do (features)?
1. it gets data from an Api (recipes)
2. it searches for the chosen dish of the day
3. the recipe can be saved as a favorite (Create, Read, Delete).
4. there exist also a place for saved searches, cause if I see a very good dish but unfortunately couldn't save it, it is all good and saved in a separated place called "Saved before"
5. searching by countries, you can easily search any available dish according to its country


Future additions that I would love to have:
1. more dynamic, modern animations
2. better performance
3. some better code optimization
4. dark and light mode
5. more backend features
